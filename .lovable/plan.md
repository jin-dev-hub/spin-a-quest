
# NextStep - 스마트 랜덤 이동 및 활동 가이드

## Overview
선택 장애를 해결해주는 모바일 웹 서비스. 원페이지 스크롤 레이아웃에 3개의 카드 섹션으로 구성.

## 데이터
- **지하철 데이터**: 1~9호선, 경의중앙선, 신분당선 주요역을 JSON으로 정의 (서울/수도권 구분, 노선별 브랜딩 컬러)
- **액션 프리셋**: Food 8종, Activity 8종

## 주요 기능 카드

### 카드 1: 호선 선택기
- 노선별 브랜딩 컬러 칩(Chip) UI
- 전체 선택/해제 토글
- 서울/수도권 범위 필터
- "랜덤 호선 뽑기" → 슬롯머신 애니메이션 후 결과 확정

### 카드 2: 역 선택기
- 선택된 호선 기반으로 랜덤 역 뽑기
- 슬롯머신 효과 (텍스트 위아래 빠르게 스크롤 후 정지)
- 결과 확정 시 scale-up + 색상 피드백

### 카드 3: 할 일 선택기 (Custom Todo List)
- 직접 입력 (최대 10개) + 리스트 뷰
- Food/Activity 프리셋 버튼 → 클릭 시 리스트 즉시 교체
- 입력된 항목 중 랜덤 선택 → 슬롯머신 애니메이션

## 공통 인터랙션
- 버튼 클릭 시 즉시 disabled → 1.5~2초 슬롯머신 → 결과 확정 후 re-enable
- 체크박스/리스트 추가·삭제 시 슬라이딩 애니메이션
- 터치 타겟 최소 44px, 모바일 최적화

## 디자인
- 밝고 경쾌한 톤, 각 노선 컬러를 포인트로 활용
- framer-motion 활용한 슬롯머신 및 마이크로 인터랙션
- 카드 기반 원페이지 스크롤 레이아웃
